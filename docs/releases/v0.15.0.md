# What Framework 0.15.0

0.15 keeps React's familiar names and call shapes and puts an entirely new
engine underneath them. It is a breaking release: upgrade every What package
together, recompile, and follow [UPGRADING.md](../UPGRADING.md). The full list
of changes is in [CHANGELOG.md](../../CHANGELOG.md).

## The engine

- A push-pull signal engine with an owner tree. Components run once; an
  effect owns what its run creates, and a component owns everything it
  creates.
- Async values in the graph. A `computed()` that returns a promise fetches,
  aborts a superseded run and keeps its last value meanwhile. `<Suspense>`,
  `startTransition`/`useTransition`, `useOptimistic`, `use()` and `settled()`
  read it, with React's API shapes.
- Development code is compiled out of production builds. what-core,
  what-router and what-server export a production tier, a bundler tier and
  their source, by export condition.

## Server and hydration

- A compiled server target, buffered and out-of-order streaming, and a
  response a render can set its status, headers and redirect on.
- Hydration by adoption: matching server markup creates no nodes and is not
  fetched again. A mismatch is reported as a structured record, only the
  differing part is rendered on the client, and the page ends up holding what
  a client render would.

## Data, actions and routing

- `query()` and one query cache under `useQuery`, `useSWR`,
  `useInfiniteQuery` and `useFetch`.
- React 19's `useActionState` and `useFormStatus`. Server actions run as
  transitions and revalidate inside them. CSRF is checked by Fetch Metadata and
  `Origin`, so forms on cached pages post without a token.
- Navigations are transitions that prepare the destination before they commit.

## Tools for agents

- One coded diagnostics channel and a catalogue of 66 codes, each with a fix
  and an example ([ERRORS.md](../ERRORS.md)).
- 25 MCP tools, including `what_why` and `what_events`.
- eslint-plugin-what rewrites the moved imports (`eslint --fix`).

## Before you upgrade

- The root entry went from 177 names to 58; the kits moved to subpaths.
- The server and the client must run the same release: the hydration
  protocol changed.
- Every behaviour change, with its migration, is in
  [UPGRADING.md](../UPGRADING.md#behaviour-changes).
