# What Framework 0.13.10

## Imported values in compiled JSX

what-compiler no longer calls an imported binding used as an attribute value.
`<a href={DOCS_URL}>` with `export const DOCS_URL = '/docs'` used to compile to
`DOCS_URL()` and throw `DOCS_URL is not a function` at render. Imports are now
passed through uncalled, and the runtime setters resolve a function value as a
reactive accessor, the same way `h()` does. Imported strings, numbers, class
names and style objects render, and imported signals, computeds and accessor
functions still update the attribute. Named, default and namespace imports
behave the same way.

`<Show when={X}>` and `<Match when={X}>`, where `X` is an import or a
destructured prop, compile to `typeof X === 'function' ? X() : X`, matching the
components' own runtime check. An imported boolean flag no longer throws.

## Attribute aliases on the server

`renderToString`, `renderToStream` and `renderDocument` now write `for` for
`htmlFor`, so server-rendered labels are associated with their inputs.
`httpEquiv` and `acceptCharset` become `http-equiv` and `accept-charset`, on the
server and in what-compiler's static templates.

## New template: static site with islands

`npm create what@latest my-site -- --template=islands` scaffolds JSX pages
prerendered to static HTML, with interactive islands that hydrate in place. It
has two pages, one shared layout and one island. `npm run build` writes one HTML
file per page into `dist/`, and a page without islands runs no framework code.

## Scope

Found by Little Friend, a production app built on What 0.13.9. No new
dependencies. The maintained fixed-version group contains 13 packages, and
deprecated `what-mcp` remains frozen at 0.12.4.
