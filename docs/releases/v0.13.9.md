# What Framework 0.13.9

## Consistent static export snapshots

Static and hybrid exports now resolve each concrete page's loader once. The
HTML, embedded hydration payload and `__what_data.json` navigation response
share that result. Previously, a changing loader could supply different data
to the initial page and its client-navigation response.

Custom renderers can still prepare the request context before calling the
page module's loader. Repeated reads reuse its promise, including `undefined`
results and failures. Each URL and each export run owns a new snapshot; the
caller-owned route is not mutated. A rejected loader prevents artifacts from
being written for that page.

Rebuild and redeploy existing static output to obtain consistent snapshots;
upgrading a package does not rewrite previously exported HTML or data files.

## Scope

This is a build-time export fix, with no new dependencies or rendering modes.
The repository lockfile also updates the existing MCP tooling's transitive
Hono dependency from 4.13.1 to 4.13.9 for the current security audit gate.
The maintained fixed-version group contains 13 packages. Deprecated `what-mcp`
remains frozen at 0.12.4. Island retry/lifecycle fixes, streaming/PPR work and
paired compiler SSR/hydration are separate work, not part of this patch.
